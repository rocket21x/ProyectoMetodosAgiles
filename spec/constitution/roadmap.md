# Roadmap

## Hecho ✅

1. **001 · Registrar proveedor (HU-1)** — Formulario y API para que un usuario se registre como proveedor y cree su negocio.
2. **002 · API Gateway** — Gateway central que orquesta y redirige peticiones a los microservicios.
3. **003 · AuthService** — Registro, login con JWT y validación con Joi.
4. **004 · Customer-to-provider** — Upgrade de rol customer a provider al crear un negocio.
5. **005 · React Router + Header** — Navegación interna con React Router v6 y menú de usuario.
6. **006 · Payment scaffold** — Estructura inicial del servicio de pagos.

## Siguiente 🔜

7. **007 · Pagos con Stripe/Conekta** — Integración de pasarela de pagos real en PaymentService.
8. **008 · Reseñas y valoraciones** — CRUD de reviews con rating y comentarios.
9. **009 · Notificaciones** — Sistema de notificaciones (email o push) para confirmaciones y recordatorios.
10. **010 · Panel admin** — Dashboard de administración para supervisar la plataforma.

## Backlog / ideas 💡

- **Búsqueda y filtros** — Búsqueda de experiencias por ubicación, categoría y precio.
- **App móvil** — Versión nativa o PWA para dispositivos móviles.
